# academic-hub-frontend

Aplicación web de Academic Hub: React + Vite + TypeScript + CSS Modules.

```bash
npm install
npm run dev     # http://localhost:5173 — requiere la API en http://127.0.0.1:4000
npm run build
```

El login usa la cuenta propia de Academic Hub, nunca las credenciales del campus virtual.

- `docs/FRONTEND_DESIGN_SYSTEM.md` — paleta, tipografía, tokens, componentes, movimiento y accesibilidad.
- `docs/FRONTEND_IMPLEMENTATION.md` — rutas, conexión con la API, bibliotecas y verificación.
